# Dependency Policy

## Purpose

Define the dependency policy standard for DocuPress CMS.

## Acceptance criteria

- The dependency policy requirement is explicit and testable.
- Editorial and reader impact is considered.
- Netlify and Git Gateway implications are documented.
- Recovery steps are repeatable.

- [ ] Run `pnpm build`.
